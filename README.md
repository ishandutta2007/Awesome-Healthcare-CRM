# Awesome-Healthcare-CRM

## Top Healthcare CRM Tools Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Patient Relationship Management, Care Coordination & Clinical Workflow Automation*  

**Last updated: March 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Healthcare CRM Tools**. These tools help hospitals, clinics, and healthcare organizations manage patient relationships, coordinate care across providers, automate appointment scheduling, and maintain compliant communication — all while supporting the unique regulatory requirements of healthcare data.



**Examples** include Salesforce Health Cloud, Veeva Systems, Epic Healthy Planet, Cerner HealtheIntent, Innovaccer, Mercury Healthcare, LeadSquared Healthcare, Healthgrades, Wellsky, and CareCloud (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom patient workflows, and transparent clinical data management — ideal for clinics prioritizing data sovereignty, developers building healthcare platforms, and organizations avoiding per-patient pricing.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects



- **[OpenHealthCRM](https://github.com/pras75299/OpenHealthCRM)**  

  Open-source healthcare CRM built with Next.js 16 and Prisma for multi-tenant clinic operations. Features staff authentication with RBAC, patient management, appointments, encounters, labs, billing, communications, audit logging, patient portal access, and live vitals streaming. Docker-based deployment with PostgreSQL and Redis. Note: Not presented as turnkey HIPAA-compliant production deployment .



- **[OpenEMR](https://github.com/openemr/openemr)**  

  The most popular open-source electronic health records and medical practice management solution. Features fully integrated EHR, practice management, scheduling, electronic billing, and patient portal. ONC certified. Runs on Windows, Linux, and Mac OS X. GPL licensed .



- **[VITALIt](https://github.com/basedavishkar/vitalit-os)**  

  Free, open-source hospital management system built to replace expensive, outdated enterprise software. Features full patient, doctor, appointment, billing, inventory, and admin modules with role-based access control and real-time dashboards. 100% self-hostable with no vendor lock-in. MIT licensed .



- **[Imhotep Smart Clinic](https://github.com/Imhotep-Tech/imhotep_smart_clinic)**  

  Modern medical clinic management system built with Django and TailwindCSS. Features digital medical records, smart appointment scheduling, prescription management, and practice analytics. PostgreSQL database with PWA support for mobile access .



- **[Marley Health (Frappe Health)](https://github.com/earthians/marley)**  

  Open-source, enterprise and modern health information system built on Frappe/ERPNext framework. Features patient management, outpatient/inpatient management, clinical procedures, rehabilitation, physiotherapy, and laboratory management. Design based on HL7 FHIR standards. GPL-3.0 licensed .



- **[PatientCrm](https://github.com/dotnetappdev/PatientCrm)**  

  Open-source patient CRM built with .NET 10, ASP.NET Core, and Blazor. Features role-based and claims-based authorization, account lockout, HTTPS enforcement, secure cookie policies, TOTP 2FA, and passkey (FIDO2/WebAuthn) support. SQL Server backend with Swagger/OpenAPI documentation .



- **[BHIMA](https://github.com/Ebed-meleck/bhima)**  

  Free, open-source accounting and hospital information management system (HIMS) tailored for rural hospitals. Features income/expense reporting, budgeting, patient billing, inventory, and purchasing. Designed to scale from single clinic to multi-hundred bed institution. GPL-2.0 licensed .



- **[OpenMRS](https://github.com/openmrs/openmrs-core)**  

  Open-source medical record system designed for developing countries. Features patient records, clinical workflows, and modular architecture. Supports FHIR interoperability standards .



- **[LibreHealth EHR](https://github.com/LibreHealthIO/lh-ehr)**  

  Free and open-source electronic health records system with clinical decision support, prescription management, and practice management. Fork of OpenEMR with modernized architecture .



### Additional Strong Open-Source Options



- **[HospitalRun](https://github.com/HospitalRun/hospitalrun-frontend)** — Open-source hospital information system for developing world hospitals. Features patient records, scheduling, and offline-first architecture .

- **[Open Hospital](https://github.com/informatici/openhospital)** — Free and open-source EHR software application for hospital management .

- **[OpenClinic](https://github.com/ldpercy/openClinic)** — Open-source health information system with patient records and clinical data management .

- **Interoperability Tools** — OpenFGA for relationship-based access control modeling HIPAA-regulated PHI access, care-team scoping, and PHI vs. non-PHI field-level permissions .

- **FHIR Servers** — HAPI FHIR, Medplum for healthcare data interoperability.



**Frameworks for building custom systems**: Combine **OpenEMR** or **OpenMRS** for clinical records, **Marley Health** for ERP-integrated healthcare workflows, **OpenHealthCRM** or **PatientCrm** for patient relationship management, and **OpenFGA** for HIPAA-compliant access control to build a complete self-hosted healthcare CRM stack.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Healthcare CRM tools must comply with data protection regulations (GDPR, HIPAA, HITECH), industry standards (HL7 FHIR, ONC certification), and clinical data governance requirements.

- Self-hosted open-source solutions require proper security hardening, HIPAA compliance verification, and ongoing maintenance.
